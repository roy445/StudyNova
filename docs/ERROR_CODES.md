# StudyNova AI 錯誤代碼手冊

> 每一個錯誤都有專屬代碼，格式 `SN-<類別>-<編號>`。
> 在畫面上看到代碼時，可以到 **/faq → 錯誤代碼查詢** 輸入代碼，或直接點「回報問題」自動帶入。

## 代碼結構

| 部分 | 說明 |
| --- | --- |
| `SN` | StudyNova 固定前綴 |
| 類別 | AUTH / ACCT / REQ / PERM / QUOTA / NOVA / AI / FILE / WEEK / SOCIAL / ADMIN / RATE / SYS |
| 編號 | 4 位數字（已文件化）或 4 位十六進位（動態推導） |

### 兩種代碼

1. **已文件化代碼**（例如 `SN-AI-6001`）：共 90 組，列於下方表格，具有固定的說明與處理建議。
2. **動態代碼**（例如 `SN-REQ-A1B2`）：由錯誤訊息以 SHA-256 推導，**同樣訊息永遠得到同一組代碼**，因此依然可被搜尋與統計，只是尚未收錄於本文件。

### 錯誤回應格式

所有 API 錯誤都會回傳統一結構，並在 HTTP 標頭附上 `x-studynova-error` 與 `x-request-id`：

```json
{
  "ok": false,
  "error": {
    "code": "SN-QUOTA-4001",
    "message": "今日「圖片辨識」已達上限（5 次）",
    "hint": "明天 00:00 會自動重置，或升級 Nova Pro 取得更高額度。",
    "requestId": "REQ-9F2C81A0B4",
    "docs": "/faq?code=SN-QUOTA-4001"
  }
}
```

- `code`：專屬錯誤代碼
- `hint`：可採取的行動
- `requestId`：追蹤編號，管理員可用它在 System Log 中找到該次請求
- 錯誤訊息永遠不會包含 API Key、Token、Cookie、SQL 或伺服器路徑

## AUTH｜帳號與登入

| 代碼 | HTTP | 說明 | 處理建議 |
| --- | --- | --- | --- |
| `SN-AUTH-1001` | 401 | 請先登入 | 你的登入狀態已失效，請重新登入後再試一次。 |
| `SN-AUTH-1002` | 401 | NOVA ID／Email 或密碼不正確 | 請確認大小寫是否正確；忘記密碼可使用「忘記密碼」重設。 |
| `SN-AUTH-1003` | 401 | 此帳號已被停用 | 請透過「回報問題」聯絡管理員了解原因。 |
| `SN-AUTH-1004` | 401 | 登入階段已過期 | 為了保護你的資料，登入超過 14 天會自動失效，請重新登入。 |
| `SN-AUTH-1005` | 409 | 此 Email 已註冊 | 請直接登入，或使用「忘記密碼」重設密碼。 |
| `SN-AUTH-1006` | 409 | NOVA ID 產生失敗 | 這是極少見的情況，請重新送出註冊。 |
| `SN-AUTH-1007` | 400 | 重設連結無效或已過期 | 重設連結 30 分鐘內有效且只能使用一次，請重新申請。 |
| `SN-AUTH-1008` | 400 | 重設連結已被使用 | 請重新申請一組新的重設連結。 |
| `SN-AUTH-1009` | 400 | 目前密碼不正確 | 請重新輸入目前的密碼；若已忘記請登出後使用忘記密碼。 |
| `SN-AUTH-1010` | 400 | 擁有者帳號不可自行刪除 | 請先將擁有者權限轉移給其他管理員。 |

## 回報流程

1. 記下畫面上的 **錯誤代碼** 與 **追蹤編號**。
2. 前往 `/faq` 查詢代碼，多數問題會有立即可行的解法。
3. 仍未解決 → `/support` 回報問題（代碼會自動帶入），送出後取得單號 `SN-T-日期-XXXX`。
4. 於「我的回報」或「用單號查詢」追蹤處理進度；狀態變更時會收到站內通知與推播。

## 管理員排查

- **後台 → 問題回報**：依狀態篩選、查看最常被回報的錯誤代碼、回覆並更新狀態（自動通知回報者）。
- **後台 → 系統 → System Log**：以 `requestId` 搜尋伺服器端紀錄。
- **後台 → AI・內容 → AI Health**：查看 AI 失敗分類與冷卻狀態。
