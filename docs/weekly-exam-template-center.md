# 英文隨堂考範本中心

英文範本中心整合在既有的英文隨堂考後台，不建立第二套考試或題庫。範本只描述正式考卷的結構、題型、題數、配分、作答方式與出題規則；範本原題不會直接提供給學生。

## 流程

管理員在「Admin → 英文隨堂考 → 考試範本中心」上傳 PDF、JPG 或 PNG 範本，填寫名稱、用途、年級、教材、範圍及備註。系統保存範本與 `Template v1`，管理員再執行 AI 分析。AI 依影像辨識題號、大題、題型、題數、配分、選項、作答方式及出題邏輯，並以結構化資料保存分析結果。

分析完成後會執行 Validation。`totalQuestions` 必須等於各大題題數總和；各大題百分比必須合計 100%；每題配分與總分必須一致；每一大題必須具有題型規則。驗證失敗的版本不可啟用，也不可用於正式出題。

管理員可查看原始範本、結構預覽、模擬考卷結構與 JSON。人工修改不會覆蓋舊版本，而是建立新的 Template Version。舊版本可保留給已使用它的正式考試，避免格式變更破壞歷史資料。

啟用的範本版本可在既有英文隨堂考週次的「開放設定」指定。既有 AI 分析／草稿流程會讀取該版本的動態結構，並要求正式草稿符合範本題數；流程仍會經過草稿、管理員確認後才進入既有英文隨堂考題庫與學生線上測驗。

## 用途

`UNIT_TEST` 已支援完整範本分析與版本化流程。`WEEKLY_EXAM` 目前只建立分類、入口與資料欄位，不推測任何週考格式。`COMPREHENSIVE` 與 `OTHER` 可保存範本，但仍需依實際範本完成分析與人工確認。

## 資料表

`weekly_exam_templates` 保存範本的基本資料與目前啟用版本；`weekly_exam_template_versions` 保存每個不可變版本、原始來源、AI 分析結果、題型結構、配分、人工變更與驗證錯誤。既有 `weekly_exam_weeks.template_version_id` 用於指定正式英文隨堂考版本，既有 `weekly_exam_drafts.template_version_id` 用於追蹤生成草稿使用的版本。

## 重要安全規則

範本分析失敗或圖片品質不足時，系統不會硬猜，版本會標記為 `failed` 並提示重新上傳清楚檔案。範本未通過 Validation 時不能啟用。已被正式週次使用或目前啟用的範本不能直接刪除；歷史版本與正式題目會保留。
