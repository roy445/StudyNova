# A. 學生手冊

## A1. 註冊與 NOVA ID

1. 打開首頁 → 點「免費註冊」。
2. 填寫 **顯示名稱**、**Email**、**密碼（至少 8 字）**。
3. 送出後系統立即建立帳號，**不需要 Email 驗證**。
4. 畫面會顯示你的專屬 **NOVA ID**（格式 `NV-XXXX-XXXX`），可以：
   - 📋 **複製**
   - 📱 **QR Code**（分享給同學掃描加好友）
   - 🔗 **分享**（優先使用手機原生分享）

**關於 NOVA ID**

| 特性 | 說明 |
| --- | --- |
| 產生方式 | 由伺服器產生，前端無法指定或偽造 |
| 唯一性 | 全球唯一，註冊時會重複檢查 |
| 內容 | 不含 Email、不含真實姓名 |
| 可否修改 | 不可修改（避免身分混淆） |
| 用途 | 公開識別碼：加好友、分享、排行榜顯示 |

**登入方式**：NOVA ID + 密碼，或 Email + 密碼。
登入失敗一律顯示 `SN-AUTH-1002`，不會透露帳號是否存在（安全設計）。

**忘記密碼**：登入頁 → 忘記密碼 → 輸入 Email → 取得一次性連結（30 分鐘有效、只能用一次）→ 設定新密碼 → 所有裝置自動登出。

## A2. 首次設定（Onboarding）

註冊後會進入 3 步驟設定，這些設定**會真的影響系統行為**：

| 設定 | 影響 |
| --- | --- |
| 學制 / 年級 | AI 出題難度、教材整理用語 |
| 每日學習目標（分鐘） | Dashboard 進度條、今日讀書計畫總時數 |
| 偏好 / 想加強科目 | 讀書計畫科目權重、Novi 建議 |
| 英文程度（A1–C1） | 每日單字挑選範圍 |
| 每日單字量 | 單字頁一次出現幾個 |
| 提醒時間 | 學習提醒排程 |
| AI 主動提醒頻率 | Novi 主動提示的積極程度 |

隨時可在「我的 → 學習設定」修改，修改後立即生效（成功會顯示提示，失敗可重試）。

## A3. Dashboard 首頁

由上到下：

1. **跑馬燈**：管理員設定的重要公告、限時活動、每週小考開放狀態。
2. **🤖 Novi 今天建議**：依你的真實資料生成，例如
   *「你的數學最近進步很多，但英文文法錯題增加，我建議今天花 15 分鐘複習。」*
3. **四格統計**：今日學習分鐘 / 連續學習天數 / Nova 點數 / Novi 等級。
4. **今日目標進度**：進度條 + 三個快捷入口（專注計時、錯題複習、今日單字）。
5. **🗓️ AI 今日讀書計畫**：勾選完成即記錄學習時間並發放獎勵。
6. **✅ 今日任務**：達成後按「領取」才會發 Nova / XP（防重複領取）。
7. **⏰ 考試倒數**：距離段考剩幾天。
8. **📈 成績趨勢**：折線圖 + 最弱科目提示。
9. **🎉 進行中的活動**、**📢 公告與每週小考**、**🧾 最近成績**。

## A4. Novi AI 小助理

Novi 是漂浮式球形 AI（不是真人），固定在右下角，**不會遮住手機底部導覽列**，可以 `－` 縮小或 `✕` 收合。

**快捷面板**：今日建議 / 弱點分析 / 問 AI / 最近錯題 / 今日任務進度。常見問題與回報問題固定放在網站 footer。

**八種模式**（在 AI 頁切換）：

| 模式 | 用途 |
| --- | --- |
| 學習教練模式 | 循序講解、確認理解程度 |
| 解題模式 | 完整步驟 + 答案 + 常見錯誤 |
| 提示模式 | **不給答案**，只給引導問題 |
| 考試模式 | 出題、評分與講評 |
| 筆記模式 | 整理成結構化 markdown 筆記 |
| 錯題模式 | 找錯誤原因、更簡單解法、類似題 |
| 複習模式 | 排複習順序與間隔重複建議 |
| 快速模式 | 3 句內給結論 |

**資料授權**：對話上方可勾選 `學習設定 / 成績 / 錯題 / 讀書計畫 / 待辦 / 指定教材`。**沒有勾選就不會傳送**。

**AI 動作確認**：Novi 想建立任務、筆記、測驗或修改今日計畫時，只會「提出建議」，畫面顯示完整預覽與 JSON，你按下「確認執行」後伺服器才會驗證並寫入。**AI 不能靜默修改任何資料。**

**Novi 記憶**：Novi 會記住重要偏好，可在「🧠 Novi 記憶」逐筆刪除。

## A5. 學習中心

十個分頁：

### 🗓️ 今日計畫
自動依「成績弱點 + 錯題壓力 + 考試接近度 + 偏好科目」計算各科分鐘數，可重新計算、勾選完成、管理待辦與作業。

### 📚 教材
- 上傳 PDF / TXT / 圖片，或直接貼上文字。
- 上傳後自動擷取文字（圖片與 PDF 會用 AI，消耗「教材整理」額度）。
- 「AI 整理」會產生摘要、重點、單字、重要句子，並自動建立一份筆記。
- 可切換「私人 / 可分享」。

### 🖼️ 圖片 OCR
1. 建立辨識文件 → 選擇圖片或直接拍照（可多張）。
2. 每頁可 **上移 / 下移 / 旋轉 / 清除標記 / 刪除**。
3. 在圖片上 **拖曳** 即可框選：
   - **螢光筆模式**：黃(本次考試) / 綠(重要) / 藍(句子) / 粉(單字) / 橘(注意)
   - **裁切模式**：只保留框內區域
4. 按「✨ 開始 AI 辨識」→ 文字出現在下方，**可直接修改**（失焦自動儲存）。
5. 一鍵轉換：整理筆記 / 找重點 / 出題 / 解題 / 記憶卡 / 翻譯 / 易錯提醒 / 複習計畫。

**拍不清楚？** 光線充足、文字水平、填滿畫面、先裁切再辨識。

### 📝 測驗
- **AI 出題**：選科目、難度（簡單/普通/困難/會考/高難度）、題型（單選/多選/填空/是非/簡答/閱讀/混合）、題數，來源可選教材或貼上文字。
- **錯題複習卷**：一鍵用錯題生成測驗。
- 作答時：**倒數計時**、**每題自動儲存**、可「稍後再作答」中斷後恢復、時間到自動交卷。
- 交卷後：分數、逐題解析、答錯自動進錯題本、可分享成績卡。

### 🎯 錯題本
每題記錄錯誤次數、複習次數、**熟練度 0–100%**、下次複習時間。
「我會了」+25%、「還不熟」−15%；達 100% 自動結案並發獎勵。
「AI 記憶法／更簡單解法」會給更簡單解法、記憶方法、類似題與下次複習建議。

### 🔤 單字
五種模式：單字卡 / 英→中 / 中→英 / 拼寫 / 限時挑戰（60 秒）。
熟悉的單字出現頻率降低、不熟的提高。支援 🔊 發音與 🧠 AI 記憶法（聯想、字根、故事、發音提示、易混淆對比）。

### 💬 句子
中→英 / 英→中 / 關鍵字填空，支援朗讀與熟悉度追蹤。

### 🎤 錄音
三種模式：**朗讀評分 / 背誦測試 / AI 口說**。
操作：開始 → 暫停 → 繼續 → 結束 → 播放 → 重錄 / 送出。
AI 會輸出逐字稿與 **總分 + 流暢度 / 正確度 / 完整度 / 語速**，列出漏讀字詞與改善建議。

### ⏱️ 計時
15 / 25 / 45 / 60 分鐘或自訂；開始 / 暫停 / 重設 / 提前完成。
完成後**必須選科目並寫反思**，資料寫入成功才算完成，並更新今日分鐘、連續天數、Nova、XP、週報。

### 🗒️ 筆記
手動建立或由 AI / OCR 自動產生，可編輯、建立分享卡、刪除。

## A6. 成績管理與 AI 分析

**新增成績**：科目、考試名稱、類型（段考/小考/模擬考/作業/平時）、日期、滿分、實得分數、範圍、班平均（選填）、備註。

**自動計算**：百分比、平均、最高、最低、趨勢（上升 / 下降 / 持平 / 波動）與變化幅度。

**AI 分析**：只根據真實數據，例如
*「數學 68 → 75 → 81 → 84，目前呈現上升趨勢（平均 77）。」*
沒有資料時會明確告知（`SN-REQ-2009`），不會亂下結論。

**目標分數**：設定「目前 72 → 目標 85」，系統持續追蹤；達成時自動發放 Nova + XP + 成就。

**考試倒數**：新增考試後首頁顯示「距離段考還有 12 天」，並自動調整讀書計畫權重。

## A7. 每週小考

**開放時間**：預設週六、日，但管理員可自由設定任何星期與時間、手動開放／關閉、臨時開放、重新開放歷史週次。未開放時顯示 `SN-WEEK-8002`。

**六個分頁**：

| 分頁 | 內容 |
| --- | --- |
| ⚡ 快速背誦 | **10 分鐘快速複習**：1 分預覽 → 3 分單字 → 3 分句子 → 2 分測驗 → 1 分弱點；含單字卡 |
| 🔤 本週單字 | 管理員確認發布的單字，附中文與例句、螢光筆語意標籤 |
| 💬 本週句子 | 中英對照 |
| 📝 模擬測驗 | 每人一次正式作答，自動儲存、交卷後看解析 |
| 📄 考卷 | 考卷圖片；**答案卷只有在你完成測驗後才會顯示** |
| 📊 成績統計 | 參與人數、平均、最高、我的分數、排名、背誦完成率 |

部分週次可能需要 Nova 入場費或限 Nova Pro，畫面會事先標示。

## A8. 好友・挑戰・讀書房・活動

- **好友**：輸入對方 NOVA ID 送出邀請 → 對方接受。支援 QR Code、取消、拒絕、移除、封鎖 / 解除封鎖。雙方同時邀請會自動成為好友。
- **挑戰**：單字挑戰或測驗挑戰，可設定時限，完成後登錄成績並顯示 🥇🥈🥉 排名，發放 Nova / XP。
- **讀書房**：建立好友讀書房或班級，用 6 碼邀請碼加入。顯示每位成員今日專注分鐘與共同目標進度。
- **活動**：管理員發布的週末加倍、節日挑戰、限時挑戰等，達成目標值自動發獎（只發一次）。
- **排行榜**：本週學習時間榜 + XP 榜，可切換全站 / 好友。

## A9. Nova / XP / Novi 養成 / Nova Pro

**Nova（可花費點數）**：學習、每日任務、測驗、活動、成就、連續學習、分享、管理員贈送。
**XP（只增不減）**：用於 Novi 等級、徽章、成就、排行榜。
兩者完全分離，皆由後端 Ledger 記錄，前端無法修改。「我的 → Nova 紀錄」可查每一筆明細。

**Novi 五個等級**

| 等級 | 名稱 | 需求 XP | 升級花費 | 解鎖能力 |
| --- | --- | --- | --- | --- |
| Lv.1 | 初始助手 | 0 | 0 | 基本問答與今日建議 |
| Lv.2 | 智慧助手 | 300 | 150 Nova | 錯題分析與記憶法 |
| Lv.3 | 學習專家 | 1200 | 400 Nova | 讀書計畫優化、朗讀評分 |
| Lv.4 | AI 大師 | 3000 | 900 Nova | 多圖分析、深度出題（外觀出現星軌） |
| Lv.5 | AI 核心 | 6000 | 2000 Nova | 全功能與專屬星軌特效 |

**Novi 商店**：外觀、核心、特效、漂浮、聲音、稱號、徽章、虛擬通行證。購買後在「Novi 養成」切換裝備（未擁有無法裝備）。

**Nova Pro**
- **不是付費商品**，站上沒有任何刷卡或訂閱功能。
- 只能由管理員授予 / 延長 / 回收，或用管理員發放的優惠碼兌換天數。
- 權益：金色身分與徽章、專屬視覺、**學習獎勵雙倍 Nova 與雙倍 XP**、全部進階 AI 額度。

**免費版 vs Nova Pro 每日額度（預設值，管理員可調）**

| 功能 | 免費 | Nova Pro |
| --- | --- | --- |
| 情境 AI | 12 | 80 |
| AI 練習出題 | 3 組 | 15 組 |
| 教材整理 | 3 | 15 |
| AI 讀書計畫 | 關閉 | 5 |
| 錯題 AI 複習 | 5 | 30 |
| AI 朗讀 / 語音分析 | 關閉 | 20 |
| 圖片辨識 | 5 張 | 50 張 |
| 多圖片辨識 | 關閉 | 10 |

實際額度以「我的 → 我的通行證」顯示為準。額度用完顯示 `SN-QUOTA-4001`（隔日 00:00 重置）。

## A10. 學習報告與分享

「學習報告」可切換 **本週 / 上週 / 本月**，顯示學習時間、連續天數、任務完成、Nova/XP、每日專注長條圖、科目時間圓餅圖、錯題改善率、測驗成績走勢與各科趨勢，並可一鍵產生分享卡。

**分享**優先使用手機原生分享（Web Share API），不支援時自動複製連結。分享卡是獨立公開頁 `/s/<slug>`，只包含你選擇分享的內容。

## A11. 通知與推播

- 站內通知：右上角 🔔，含未讀數字、可單筆或全部標為已讀。
- Web Push：「我的 → 安全與通知 → 開啟推播」，可送測試推播。iOS 需先「加入主畫面」。
- 通知具備去重機制，同一事件不會重複打擾。

## A12. 遇到問題怎麼辦

1. 畫面上的錯誤都會顯示 **專屬錯誤代碼**（例如 `SN-AI-6001`）與 **追蹤編號**（`REQ-XXXXXXXXXX`）。
2. 到 **常見問題 `/faq`** → 「錯誤代碼查詢」輸入代碼，看原因與解法。
3. 仍未解決 → **回報問題 `/support`**（代碼會自動帶入），填寫分類、嚴重程度、重現步驟，可附截圖。
4. 送出後取得單號 `SN-T-日期-XXXX`，可在「我的回報」或「用單號查詢」追蹤；狀態變更會收到通知。

# B. 管理員手冊

> 所有新註冊使用者預設為 `student`。管理員資格請在 Neon SQL Editor 執行 `database/admin-role.sql`，由管理者明確授權。
> 入口：只有 `admin`／`owner` 角色可進入 `/admin`。

## B1. 總覽・使用者

- **總覽**：總使用者、Nova Pro 人數、流通 Nova、本月 AI 呼叫、總學習分鐘、週次數、近 14 天註冊長條圖。
- **使用者管理**：搜尋 NOVA ID / Email / 名稱，勾選後**批次操作**：
  贈送 Nova、贈送 XP、授予 / 延長 / 回收 Nova Pro、封鎖 / 解除封鎖、重設今日額度、設定功能無限、設定角色。
  **每個操作都必須填寫原因**，並完整寫入 Audit Log（操作者、時間、對象、前後值、IP）。
- **Audit Log**：所有管理操作紀錄。

## B2. 每週小考

完整流程：

1. **建立週次**：輸入週次代碼（例 `2026-W35`）、標題、備註。
2. **上傳檔案**：`上傳本週考卷` / `上傳本週答案` / `上傳雜誌教材` / `補充檔案` —— **考卷與答案分開上傳**，可多張、可調整順序、可刪除。
3. **螢光筆語意**：預設 黃=本次考試、綠=重要、藍=句子、粉=單字、橘=注意（每週可改）。
4. **✨ 執行 AI OCR + 整理**：AI 逐張辨識 → 自動抓題目、答案、單字、句子並配對題號 → 產生 **草稿**。
   - 信心低於 60% 會標記 `⚠️ AI 不確定，請人工確認`。
5. **人工確認**：點「檢視並確認發布」，畫面顯示可編輯的完整 JSON（題目 / 單字 / 句子）。修改後按 **確認並發布**。
   - **只有確認發布後學生才看得到**；也可以「捨棄」草稿重新分析。
6. **題目・單字・句子**分頁：逐筆編輯、發布 / 取消發布、刪除，或手動新增。
7. **開放設定**：狀態（草稿/發布/封存）、開放模式（依星期排程 / 手動開放 / 手動關閉）、開放星期（可複選任一天）、起訖時間、Nova 入場費、是否限 Nova Pro、**重新開放歷史週次**（指定期間、點數、會員、名單）。

## B3. AI・會員・內容（`/admin/ops`）

- **AI Health**（每 15 秒更新）：每個 Provider 的優先順序、模型、本月請求、成功/失敗、Input/Output Token、平均延遲、Fallback 次數、最近成功/失敗、冷卻狀態、**估算成本**（標註「本地估算，不代表實際帳單」）。可啟用/停用 Provider、清除冷卻、設定費率。

## B4. 問題回報（`/admin/support`）

# C. 維運手冊

## C1. 首次部署

```bash
cp .env.example .env      # 至少填 DATABASE_URL 與 SESSION_SECRET
npm ci
npx drizzle-kit push      # 建立資料表
npm run build && npm start
curl http://localhost:3000/api/health   # 觸發冪等 Seed
```

所有新註冊者預設為 student；管理員資格請在 Neon SQL Editor 執行 `database/admin-role.sql`。

## C2. Docker

```bash
docker compose up -d --build          # app + PostgreSQL + Redis + MinIO
docker compose exec app npx drizzle-kit push
```

## C3. 降級策略（沒設定也不會壞）

| 未設定 | 系統行為 |
| --- | --- |
| `REDIS_URL` | 自動改用 PostgreSQL job queue（同樣具冪等） |
| `S3_*` | 自動改用 PostgreSQL 物件儲存 |
| AI API Key | AI 功能回傳明確的 `SN-AI-6001`，其他功能照常運作 |
| `VAPID_*` | 站內通知照常，Web Push 顯示 warning |
| `CRON_SECRET` | Cron 端點拒絕呼叫（`SN-ADMIN-9506`） |

## C4. 排程設定

```bash
curl -X POST "https://<host>/api/v1/system/cron?task=daily_tasks_refresh&uid=$(date +%F)" \
     -H "x-cron-secret: $CRON_SECRET"
```

| task | 建議頻率 |
| --- | --- |
| `daily_tasks_refresh` | 每日 00:05 |
| `review_reminder` | 每日 19:00 |
| `weekly_exam_open` | 每 30 分鐘 |
| `weekly_report` | 每週一 09:00 |
| `membership_expiry` | 每日 10:00 |
| `activity_reminder` | 每日 12:00 |
| `session_cleanup` | 每日 03:00 |

`uid` 相同時會被冪等擋下，不會重複發送通知。

## C5. 備份與還原

```bash
DATABASE_URL=... ./scripts/backup.sh backup
DATABASE_URL=... ./scripts/backup.sh restore ./backups/studynova-<stamp>.dump
S3_BUCKET=... S3_ENDPOINT=... ./scripts/backup.sh storage
```

Migration 僅採 additive 策略，**不得刪除生產資料表或欄位**。

## C6. 測試

```bash
npx vitest run     # 單元 / 邏輯測試
npm run typecheck  # TypeScript
npm run build      # 生產建置
```
再到 `/admin/system` 執行 System Test Center 做整合驗證。
