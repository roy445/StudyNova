# StudyNova 專案更新內容與生圖提示詞

以下提示詞可以直接貼給其他 AI。使用時，將 `@docs/RELEASE_NOTES_1.2.0.md`、`@docs/STUDYNOVA_IMAGE_PROMPT.md` 或你指定的其他 Markdown 檔案一起提供給 AI；如果平台不支援 `@` 語法，請直接上傳檔案。

## 通用版提示詞

你現在是 StudyNova 的品牌視覺設計師、UI/UX 設計師與產品理解助手。

請先完整閱讀我提供的 Markdown 文件，不要只看標題或摘要。請整理並理解：

1. StudyNova 目前的產品定位、主要使用者與開發初衷。
2. 這次更新新增了哪些功能、優化了哪些功能、修正了哪些問題。
3. 哪些內容是正式功能，哪些是「即將推出」或宣傳概念；不可把尚未完成的功能畫成已經可以使用。
4. 使用者要看到的版本號、中文功能名稱、限制規則、Nova／XP／Nova Pro 等名詞。
5. 網站目前的品牌風格：深色星際學習介面、青藍與紫色霓虹光、Novi 吉祥物、清楚的繁體中文資訊層級、手機優先。

閱讀完成後，先用繁體中文輸出一段「需求理解確認」，包含：

- 圖片用途與目標觀眾
- 圖片主標題與副標題
- 需要展示的功能
- 不能誤導使用者的限制或標籤
- 預計畫面構圖、色彩、裝置比例與文字區域

接著再產生圖片。請不要自行發明 Markdown 文件中沒有的價格、功能、數據、優惠、會員權限或完成狀態。若文件內容不足，請使用「即將推出」「功能規劃中」等清楚標籤，而不是假裝功能已上線。

## 生圖任務模板

請根據我提供的 Markdown 文件，製作一張 StudyNova 宣傳／功能展示圖。

- 圖片用途：`填入用途，例如首頁公告、社群貼文、Dcard、PTT、App 內公告、廣告素材`
- 目標觀眾：`填入學生／家長／英文學習者／一般大眾`
- 主題功能：`填入功能名稱`
- 圖片尺寸：`填入 1:1、4:5、16:9、9:16 或指定像素`
- 語言：繁體中文；英文單字或功能名稱只有在文件中出現時才保留英文
- 版本標籤：`例如 v1.2.0`
- 必須出現的文字：`列出 2～5 個短句`
- 必須出現的 UI：`例如 iPhone、Android 手機、首頁公告卡、任務卡、Nova 點數、Novi`
- CTA：`例如 查看詳情、開始閱讀、立即體驗、即將推出`
- 狀態：`正式開放／Nova Pro／免費版有限制／即將推出`

## StudyNova 視覺規格

請使用高級、清楚、可信任的教育科技視覺，不要做成廉價電商海報。

- 主色：深海軍藍、午夜紫、青藍霓虹、少量玫瑰粉或金色作為重點。
- 背景：星際、星軌、柔和光暈、細緻粒子；不要過度雜亂。
- 品牌角色：使用 Novi 作為友善、可靠、陪伴學習的 AI 吉祥物；表情自然，不要讓角色遮住產品資訊。
- Logo：使用提供的 StudyNova Logo，保持比例，不要重新拼寫或變形。
- 裝置展示：若需要手機展示，請同時考慮 iPhone 與 Android 的差異；畫面要像實際 App，包含圓角、狀態列／底部導覽、可讀的卡片與按鈕。
- 版面：手機版優先，375px 寬度也要能理解；文字不要貼邊、不要被裝置框或光效遮住。
- 文字：繁體中文、短句、清楚分層；不要產生簡體字、亂碼、假漢字、錯誤符號或不可辨識的小字。
- UI：公告要像真正的 StudyNova 首頁公告輪播；任務要顯示進度條、獎勵與完成狀態；作文批改要呈現文章、批改標記與建議；英文閱讀器要呈現文章、單字解析與朗讀控制。

## 常見圖片方向

### 1. v1.2.0 更新公告圖

請製作「StudyNova v1.2.0 重要更新」首頁公告／社群宣傳圖，展示新版 Novi 星旅、AI 排隊透明化、英文作文批改、英文雜誌閱讀器、每日／每週任務。每個功能以獨立小卡或手機畫面呈現，並加入「查看詳情」或「立即體驗」按鈕。若文件標記為正式功能，顯示「正式開放」；若未明確表示已開放，標示「即將推出」。

### 2. 英文作文批改展示圖

請製作學測英文作文批改專區的產品展示圖。畫面要有一支手機與一個桌面版面，顯示英文作文、段落結構建議、文法／用字標記、中文說明與改寫建議。清楚標示「免費版每日 1 次」「Nova Pro 每日 5 次」「超額可用 Nova 點數兌換」；不要寫成無限使用，也不要使用「額度」替代文件指定的 Nova 點數規則。整體要像實際產品 UI，不要像考試答案紙。

### 3. 英文雜誌閱讀器展示圖

請製作高級英文雜誌閱讀器 UI 展示圖。畫面要有雜誌文章、句子高亮、單字卡、詞性、中文意思、例句、朗讀播放控制與 Novi 協助分析。保留「英文雜誌閱讀器」與「Nova Pro」等文件中確認的文字；若文件沒有確認免費開放，不要自行宣稱免費。

### 4. 每日／每週任務圖

請製作 StudyNova 首頁任務區展示圖。每日任務要簡單，例如專注學習、完成單字練習、完成一份測驗或複習少量錯題；每張卡顯示進度條、Nova、XP 與「領取」狀態。本週任務顯示累積進度與容易完成的目標。不要設計成高壓、長時間或需要付費才能完成的任務。

## 生成前的品質檢查

在輸出最終圖片前，請自行檢查：

- 所有繁體中文是否正確、可讀、沒有亂碼。
- 版本號是否與 Markdown 文件一致。
- 功能名稱是否與文件一致。
- 是否誤把規劃中功能畫成正式上線。
- 是否誤寫免費、Pro、Nova、XP 或使用次數限制。
- Logo 與 Novi 是否存在且比例正確。
- 手機畫面在 375px 寬度下仍能理解。
- 公告、CTA、進度條與狀態標籤是否清楚。
- 沒有虛構使用者數、資料庫使用量、AI 成功率、價格或優惠。

如果圖片生成模型無法可靠產生繁體中文，請先產生「無文字或少量文字的 UI 構圖稿」，並另外輸出完整的繁體中文排版文字與每段文字應放置的位置，方便後續用 Figma、HTML 或圖片編輯工具套字。
