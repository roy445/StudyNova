# 段考衝刺：AI 題目分析必要規則

本規則適用於所有段考衝刺專區的 PDF、圖片與文件題目分析流程。規則由後端匯入流程強制執行，不能只依賴前端提示或人工記憶。

## 1. 原始檔案與頁面資產

- PDF 必須逐頁解析；每一頁的原始頁面圖片必須保存為匯入資產。
- 題目必須保存 `sourcePage`、原始檔名與匯入工作 ID。
- 若題目依賴圖片、廣告、圖表、統計表、地圖、幾何圖形或其他視覺資訊，必須掛載對應頁面圖片。
- 圖片無法可靠擷取、解析或辨識時，不得自行補圖、猜測數值或假造題幹；該題必須略過並留下原因。

## 2. 題型辨識

- 單選題：只能選一個選項，保存完整題幹與所有選項。
- 多選題：可以選多個選項，保存所有選項與多個答案；不可當成單選題處理。
- 填充／克漏字：題目必須與所屬文章或段落綁定；文章下方保存該大題全部共同選項，並保存每一題的題號、答案與填答位置。
- 閱讀題組：共同文章只建立一份題組內容，題組內各題保存相同 `groupLabel`／題組關聯；學生作答時一次顯示文章與題組題目。
- 翻譯、申論、作文、簡答、手寫題：若目前匯入流程不支援可靠的客觀作答，必須略過並標示 `unsupported_non_objective`，不可轉成選擇題。

## 3. 題目內容與答案

- 必須保存完整題幹、選項、題型、題號、頁碼與題組資訊。
- 原卷答案只作為來源答案，AI 必須重新推導；若 AI 答案與原卷答案衝突，標記 `ANSWER_CONFLICT`，交由管理員確認，不得自動覆蓋。
- 圖片或文字無法可靠判斷答案時，`verifiedAnswer` 必須留空並說明原因。
- 詳解不得使用空泛模板；必須包含理解、解題方法、答案理由、詳細解析、核心概念、常見錯誤與記憶提示。
- 選擇題的選項分析數量必須與選項數量一致；缺少選項分析時不得通過品質門檻。

## 4. 審核與發布

- AI 分析結果先建立為 draft，狀態為 `needs_review`。
- 通過 AI 品質檢查不代表可以直接給學生使用。
- 管理員必須逐題確認、修改或拒絕後，才能正式匯入段考衝刺題庫。
- 未確認題目不得進入學生端、正式題庫或正式測驗。
- 無法可靠分析的題目應保留原始頁面與略過原因，不能為了增加題數而猜測。

## 5. 資料隔離

- 原始範本、頁面圖片、分析草稿與正式題目必須分開保存。
- PDF 原題不會直接變成學生正式題庫；只有通過管理員確認的草稿才可匯入。
- 題目分析不可依賴固定的科目、題數、配分或目前某一份考卷格式；每份試卷必須依實際結構辨識。

## 6. 顯示與命名

- 段考衝刺活動使用統一格式：`第1學期 第一次段考衝刺｜科目`。
- 使用者特別指定校名或版本時，必須接在名稱後方括號，例如 `第1學期 第一次段考衝刺｜英文（屏東高中）`、`第1學期 第一次段考衝刺｜國文（龍騰版）`；未指定時不得自行添加。
- 前台活動補充說明使用「上學期」，不顯示原始試卷年份或日期。
- 原始年份、原始檔名與完整來源仍可保留在管理員 metadata，供追蹤與稽核使用。
