### 第 4 題（含圖片／公式）

**題目：** 試求 0.46 克二氧化氮中，含有多少莫耳的二氧化氮分子？其中氧原子個數有幾個？(N = 14，O = 16，Avogadro 常數 N_A = 6.02 × 10^23)

**答案：** B

**詳解：** 題目：0.46 克二氧化氮（NO2）含有多少莫耳之二氧化氮分子？其中氧原子個數有幾個？（N=14，O=16）
計算步驟：
1. 計算 NO2 的摩爾質量：M(NO2)=14 + 2×16 = 46 g·mol^-1。
2. 摩爾數 n = 質量 / 摩爾質量 = 0.46 g / 46 g·mol^-1 = 0.01 mol。
3. 分子數 = n × 阿伏伽德羅常數 = 0.01 mol × 6.02×10^23 mol^-1 = 6.02×10^21 個 NO2 分子。
4. 每個 NO2 分子含 2 個氧原子，因此氧原子總數 = 2 × 6.02×10^21 = 1.204×10^22 個。
答案對應：選項 B 為 (0.01, 1.204×10^22)。

**題目：** 下列有關原子的敘述，何者正確？

**答案：** A

**詳解：** 題目：下列有關原子的敘述，何者正確？（選一）
各選項評析：

### 第 7 題（含圖片／公式）

**題目：** 某生進行氫氣燃燒生成水蒸氣的實驗，其反應式如下：2 H2(g) + O2(g) → 2 H2O(g)。若其欲得到 15 升之水蒸氣，試問需耗去幾升的氫氣與氧氣共若干升？（選項為 15、20、22.5、25.5、50）

**答案：** C

**詳解：** 題目：反應 2H2(g) + O2(g) → 2H2O(g)。若欲得到 15 L 之水蒸氣，試問需耗去氫氣與氧氣共若干升？
分析：在相同溫度與壓力下，氣體體積與摩爾數成正比。化學當量關係：2 mol H2 + 1 mol O2 → 2 mol H2O。
因此每 2 份 H2O 對應 2 份 H2（故 H2 所需體積等於 H2O 的體積）；而每 2 份 H2O 對應 1 份 O2（故 O2 所需體積為 H2O 的一半）。
若欲得 15 L H2O，則所需 H2 = 15 L，所需 O2 = 15/2 = 7.5 L，合計 = 15 + 7.5 = 22.5 L。
結論：選 C（22.5 L）。

### 第 18 題

**題目：** 同溫、同壓下，10 mL 的 X2 氣體與 20 mL 的 Y2 氣體反應生成 20 mL 氣體化合物，則該化合物的分子式為：

**答案：** C

**詳解：** 題意：同溫同壓下，10 mL 的 X2 與 20 mL 的 Y2 反應生成 20 mL 的氣體化合物，求該化合物之分子式。
觀念與步驟：
- 在相同溫度與壓力下，氣體體積與莫耳數成正比，故可直接以體積比當作莫耳比。
- 初始：X2 的莫耳數 ∝ 10，Y2 的莫耳數 ∝ 20。反應後產物莫耳數為 20。
設產物分子式為 XpYq（每一分子含 p 個 X 原子、q 個 Y 原子）。
生成 1 摩爾產物需消耗 p/2 摩爾的 X2 與 q/2 摩爾的 Y2（因 X2、Y2 為二原子分子）。
生成 20（相對單位）莫耳產物需消耗 (p/2)·20 的 X2 與 (q/2)·20 的 Y2。
由可用量限制：(p/2)·20 ≤ 10 → p ≤ 1；(q/2)·20 ≤ 20 → q ≤ 2。
因此 p=1，q=1 或 q=2 都為整數可能。但考慮原子守恆（若反應消耗完兩者），總 X 原子數為 2×10=20，總 Y 原子數為 2×20=40，產物共有 20 個分子，平均每分子 X:Y = 20:40 = 1:2，故分子式應為 XY2。
結論：分子式為 XY2，故選 (C)。

### 第 21 題

**題目：** 下列有關濾紙層析分析法的敘述，哪些正確？（多選）

**答案：** B,C

**詳解：** 題意：有關濾紙層析（紙層析）分析法，哪些敘述正確？
各選項分析：
(A) 「利用物質密度不同分離」：錯。層析法是利用樣品與固定相（濾紙）及流動相（展開劑）間親和力（極性、溶解度、吸附力等）差異來分離，不是密度差。
(B) 「物質與溶劑間作用力愈大，展開距離愈遠」：對。若物質與流動相（溶劑）之親和力（溶解度）較大，該物質會較偏向流動相而隨溶劑上移，展開距離較遠。
(C) 「可分離出植物色素成分」：對。紙層析常用於分離植物色素（如葉綠素、類胡蘿蔔素、花青素等）。
(D) 「需在空氣中進行」：錯。實務上常把展開槽蓋起以飽和溶劑蒸氣，避免溶劑過快蒸發，故並非必須在開放空氣中進行。
(E) 「與濾紙作用力愈大的物質，展開距離愈遠」：錯。與濾紙（固定相）作用力越強，樣品會較易被吸附停留，展開距離反而越短。
因此正確為 (B) 與 (C)。

### 第 15 題（含圖片／公式）

**題目：** 已知 C(s)、CO(g)、H2(g) 的標準莫耳燃燒熱分別為 −393.9 kJ、−283.9 kJ、−285.8 kJ，且 H2O(l) → H2O(g) ΔH = 40.7 kJ，則焦炭與水蒸氣反應產生水煤氣（C(s) + H2O(g) → CO(g) + H2(g)）的反應熱為多少 kJ？

**答案：** A

**詳解：** 已知各物質之標準莫耳燃燒熱（即元素燃燒為生成氧化物時之 ΔH）：
C(s) + O2 -> CO2  ΔH = −393.9 kJ （因此 ΔHf(CO2) = −393.9 kJ）
CO(g) + 1/2 O2 -> CO2  ΔH = −283.9 kJ （此為 CO 燃燒成 CO2）
H2(g) + 1/2 O2 -> H2O(l) ΔH = −285.8 kJ （因此 ΔHf(H2O,l) = −285.8 kJ）
另 H2O(l) -> H2O(g) ΔH = +40.7 kJ，所以 ΔHf(H2O,g) = −285.8 + 40.7 = −245.1 kJ。
先由 CO 燃燒資料求 ΔHf(CO)：
CO + 1/2 O2 -> CO2 : ΔH = ΔHf(CO2) − ΔHf(CO) = −283.9
代入 ΔHf(CO2)=−393.9 得 −393.9 − ΔHf(CO) = −283.9 -> ΔHf(CO) = −110.0 kJ。
目標反應：C(s) + H2O(g) -> CO(g) + H2(g)
其 ΔH = ΔHf(CO) + ΔHf(H2) − [ΔHf(C) + ΔHf(H2O,g)] = (−110.0 + 0) − (0 + (−245.1)) = −110.0 +245.1 = +135.1 kJ。
因此反應熱為 +135.1 kJ（吸熱）。選 (A)。

**題目：** 下列有關反應熱的敘述何者正確？  
(A) 正反應的反應熱和逆反應的反應熱大小相等、符號相反  
(B) 如果反應熱為正值，則為吸熱反應，該反應不可能發生  
(C) 反應熱與反應途徑無關，僅與反應物、生成物的狀態有關

### 第 9 題（需要人工複核；含圖片／公式）

**題目：** 下列有關熱化學反應的敘述，哪些正確？  
(A) ΔH > 0 表示吸熱反應  
(B) 所有物質的燃燒都是放熱  
(C) 氯化鋰與水合氯化銀的反應是吸熱，反應於水溫下降  
(D) 5 克水在 1 ℃ 時的熱含量為 5 卡

**答案：** A,B,D,E

**詳解：** 逐項判斷：
(A) ΔH>0 表示吸熱反應，正確。
(B) 一般定義下『燃燒』為與氧劇烈反應通常放出熱量，故大多數燃燒為放熱，教科書上視為正確敘述，(B) 常視為正確。
(C) 敘述『氯化鈉與水合氯化鈉的反應是吸熱；反應導致水溫下降』文意模糊：NaCl 與其水合物之間的反應（若指溶解或水合／脫水）其熱效應依物質不同而異，題目措辭不清，本題此選項判定為不可靠，故不列為正確項（標記需審核）。
(D) 5 克水在升高 1 °C 時所吸收的熱量為 q = m·c·ΔT = 5 g × 1 cal·g−1·°C−1 × 1 °C = 5 cal，正確。
(E) 若 H2 的莫耳燃燒熱為 −286 kJ·mol−1（表示 2 H2 + O2 → 2 H2O 時每 mol H2 釋 −286 kJ），電解 36 g 水（36 g / 18 g·mol−1 = 2.00 mol H2O）可產生 2.00 mol H2（因 2 H2O → 2 H2 + O2），完全燃燒 2.00 mol H2 釋放熱量 = 2.00 × 286 kJ = 572 kJ，敘述正確。
因此可判為 A、B、D、E 為正確；但因 (C) 的原文或情境有不明之處，建議核對題意。

### 第 10 題（含圖片／公式）

**題目：** 已知 2 H2(g) + O2(g) → 2 H2O(l)，ΔH = −572 kJ，則下列敘述何者正確？  
(A) 本反應為放熱反應  
(B) 水的莫耳生成熱為 −572 kJ  
(C) 氫的莫耳燃燒熱為 −572 kJ  
(D) 本反應亦可表示為 2 H2(g) + O2(g) → 2 H2O(l) + 572 kJ  
(E) 若 2 H2(g) + O2(g) → 2 H2O(g) 的反應熱為 Q kJ，則 |Q| < 572

**答案：** A,D

**詳解：** 已知 2 H2(g) + O2(g) → 2 H2O(l)，ΔH = −572 kJ。
(A) ΔH 為負值，表示放熱反應，(A) 正確。
(B) 水的『每莫耳生成熱』（標準生成焓 ΔHf°）為 −286 kJ·mol−1（因 2 mol H2O 對應 −572 kJ），所以說為 −572 kJ·mol−1 是不正確，(B) 錯誤。

**詳解：** 當密封瓶置入熱水中時，瓶內空氣受熱，空氣分子平均動能增加（與溫度成正比），分子碰撞頻率與衝擊力增加，造成氣體壓力上升，進而使彈性塑膠鼓起。從分子觀點，直接的原因是「空氣粒子受熱能增加（平均動能上升）」。因此選 (C)。(其他選項如「粒子數增加」或「粒子本身體積變大」不符合氣體行為；粒子間間隔變大為結果之一但非直接說明「受熱」的機制；壓力變小顯然與現象相反。)

**圖片／公式區域：**

- 示意圖：一瓶子塞上彈性塑膠塞，瓶內有許多小圓點代表空氣粒子；旁邊另一圖為瓶置於盛有熱水的容器中，箭頭及水蒸氣表示受熱情形；彈性塑膠塞向外膨脹。
