# StudyNova 測試員邀請信與宣傳文案

> 用途：邀請使用者自行註冊成為 StudyNova 測試員，提前體驗 Beta 功能並提供真實回饋。

## 一、正式邀請 Email

### 建議主旨

**邀請你加入 StudyNova Beta 測試員計畫｜提前體驗 AI 相機新版**

### 信件內容

```text
{測試員稱呼} 你好：

我們正在招募 StudyNova Beta 測試員，誠摯邀請你提前體驗即將推出的新功能，並協助我們把學習工具做得更穩定、更好用。

你將可以：
・提前體驗指定的 Beta 功能
・優先使用 AI 相機新版等測試功能
・在測試員回饋看板分享心得、討論 Bug 與提出建議
・直接將問題回報給 StudyNova 團隊

加入方式很簡單：
1. 開啟測試員註冊連結：
   {測試員註冊連結}/tester/register
2. 自行建立 StudyNova 帳號。
3. 完成註冊後，系統會自動加入測試員身分組。
4. 進入測試員控制台，先閱讀指南與注意事項，再開始測試。

測試員注意事項：
・測試功能可能仍在調整，偶爾會出現錯誤或介面變動。
・請不要上傳包含姓名、電話、地址、帳號或其他個資的圖片與文件。
・發現問題時，請盡量提供操作步驟、實際結果與期待結果。
・重大問題請使用快速回報功能，不要在公開討論中貼出敏感資料。
・測試員不會取得管理員權限，也不需要管理員代為建立帳號。

快速上手指南：
{指南連結}

如果你願意協助我們測試，現在就可以加入：
{測試員註冊連結}/tester/register

謝謝你一起讓 StudyNova 變得更好！

StudyNova 團隊
```
