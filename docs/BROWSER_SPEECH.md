# StudyNova 裝置內建朗讀

StudyNova 的單字與教材朗讀使用目前瀏覽器／裝置提供的語音合成。**不需註冊 Azure、API key、外部 TTS worker 或排程；朗讀文字留在使用者裝置上，不會上傳或保存生成音檔。**

## 使用方式

1. 在單字、單字卡或教材畫面按下朗讀按鈕。
2. 若有多個語音，StudyNova 會依文字內容選擇可用的語言／聲線；單字字母與完整單字會依元件功能分開處理。
3. 若按鈕沒有聲音，先確認裝置音量、瀏覽器允許播放，並檢查系統是否已安裝所需語言的語音。可在另一個支援 Web Speech API 的瀏覽器測試。

## 語言與聲線

可用語言、聲線、離線能力與發音品質由瀏覽器及裝置作業系統決定；StudyNova 不會下載聲音模型。若要朗讀俄文等語言，請先在裝置的語音／文字轉語音設定中安裝相應語音，然後重新開啟 StudyNova。某些行動瀏覽器只會列出系統已提供的語音。

## 部署與隱私

- 不需要新增環境變數或 Vercel Cron 任務。
- 不會呼叫 Azure Speech、CosyVoice、GPT-SoVITS 或其他遠端 TTS 服務。
- 舊 `/api/v1/tts/jobs` 伺服器音檔 API 已停用，會回傳 `SN-AI-6019`。
- 為避免破壞舊部署的資料結構，既有 `tts_jobs` / `tts_segments` 資料表保留；新版本不會建立新的伺服器朗讀工作或音檔。
