## 重要概念

- **1-1**：純物質與混合物、元素與化合物、過濾、蒸餾、萃取、層析、固液氣三態、加熱曲線、相圖、三相點與臨界點。
- **1-2**：質量守恆定律、定比定律、倍比定律、道耳頓原子說、原子量、同位素、平均原子量、莫耳與粒子數換算。
- **1-3**：Thomson、Rutherford、Bohr 與現代原子模型、原子與離子、原子序、質量數、電子排列、價電子、週期表與週期趨勢。
- **1-4**：離子鍵、離子化合物、共價鍵、Lewis 結構、分子模型、共價網狀固體、金屬鍵與物質特性。

## 公式

- `Q = m s ΔT`
- `Q = mL`（相變時使用）
- `n = m/M`
- `N = nN_A`
- `平均原子量 = Σ（同位素質量 × 豐度）`
- `A = Z + N`
- `形式電荷 = 價電子 − 非鍵結電子 − 1/2 鍵結電子`

## 重要比較

- 純物質／混合物
- 元素／化合物
- 過濾／蒸餾／萃取／層析
- 固態／液態／氣態
- 定比／倍比
- 原子量／莫耳質量
- 原子／陽離子／陰離子
- 離子鍵／共價鍵／金屬鍵
- 離子化合物／分子化合物／共價網狀固體

## 可互動化內容

1. 物質分類卡片：純物質、混合物、分離方法。
2. 三態粒子模型：固態、液態、氣態的排列與運動。
3. 原子模型時間軸：Thomson → Rutherford → Bohr → 現代模型。
4. Lewis／離子鍵操作：選擇 Na⁺、Cl⁻ 並觀察離子鍵概念。
5. 隨堂選擇題：每小節至少一題，答題後顯示解析。
