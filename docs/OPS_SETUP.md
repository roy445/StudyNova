# StudyNova 運維設定

## 24 小時可用

每日單字與已發布內容是資料庫驅動，不需要使用者完成任務才能查看；首頁、學習中心與挑戰頁會持續讀取當日內容。若要讓網站在沒有使用者操作時也持續接收排程或推播，請在管理介面將網站切換到可持續運行的主機模式，並先完成部署，再建立排程。

## CRON／Heartbeat

StudyNova 的排程回呼路徑必須使用 `/api/scheduled/` 開頭，排程格式是六欄 UTC：`秒 分 時 日 月 星期`。例如每天台灣時間 08:00 是 `0 0 0 * * *`，因為台灣為 UTC+8；每天 UTC 00:00 會在台灣時間 08:00 觸發。

建立或修改排程前，流程是：先把回呼程式推送並建立 checkpoint，再部署正式網站，確認正式網址可連線後才建立排程。不要在本機開發網址上建立排程，也不要在程式內使用 `setInterval`、`node-cron` 或常駐記憶體計時器；排程要由平台觸發 `/api/scheduled/*` 回呼。

排程回呼必須驗證排程身分、使用平台提供的 task UID 查找資料，並讓工作具備冪等性。平台重試時不得重複發送獎勵、通知或建立資料。

## VAPID 推播金鑰

在安全的管理環境產生一組 VAPID 金鑰：

```bash
npx web-push generate-vapid-keys
```

將結果分別設定為以下環境變數，私鑰只能放在伺服器端，不能放進 `NEXT_PUBLIC_*` 或任何前端 bundle：

```env
VAPID_PUBLIC_KEY=你的公開金鑰
VAPID_PRIVATE_KEY=你的私密金鑰
VAPID_SUBJECT=mailto:你的管理員Email
```

使用者登入後到「個人資料／安全與通知」按下「開啟推播」，瀏覽器允許通知後會建立訂閱。管理員可用系統的測試推播確認設定；若要實際寄送，還要確認正式網站使用 HTTPS、Service Worker 路徑可存取，以及瀏覽器通知權限沒有被封鎖。

## 限定功能跑馬燈

管理員到公告管理建立公告，選擇目標受眾、開始與結束時間，勾選「跑馬燈」即可在有效期間顯示於首頁。若要通知使用者，勾選通知；若已設定 VAPID，也可另外啟用推播。PRO 限定公告應選擇 PRO 受眾並設定期限，避免活動結束後仍顯示。
