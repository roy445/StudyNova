# 110 年學測歷屆題庫匯入盤點

## 檔案概況

- 原始檔案：`110學測歷屆.pdf`
- 頁數：123 頁，A4
- 檔案是掃描影像版，沒有可直接使用的 PDF 文字層，因此採逐頁視覺 OCR 分類。
- 目前系統新增的歷屆題庫資料模型會保存：年份、考試種類、科目、題型、原卷頁碼、詳解頁碼、圖片資產 ID、正式題目與作答／錯題紀錄。

## 圖表／圖片頁

視覺分類判定含有題目必要圖表、幾何圖、化學結構、統計表、閱讀版面或其他圖片元素的頁面如下：

`1, 2, 3, 4, 6, 10, 11, 12, 13, 18–44, 55, 58–59, 63–64, 68, 71, 73–75, 78–79, 82, 84–86, 88–91, 92–104, 108–111, 112–115, 117–118, 120–123`

系統不把「圖片頁」直接塞進共用題幹文字，而是透過 `assetIds` 掛到對應歷屆題目；原始頁碼與圖片資產要一併保留，列印時能選擇顯示題目、詳解或原始圖表。

- 第 72 頁

這兩頁的視覺模型回傳 JSON 格式不完整，分類器已保留錯誤紀錄；匯入流程不得自動核准，應在後台顯示「待人工審核」。

## 後台使用方式

1. 進入 `/admin/previous-exams` 建立「110 年學測歷屆試題」。
2. 建立科目：國文、英文、數學 A、數學 B、自然、社會；科目可個別關閉。
3. PDF 題目與詳解經匯入、圖片擷取、AI 分析後，逐題人工確認，再把題庫狀態改為「已發布」並按「發布並開放」。
4. 後續新增 111、112 年時，建立新的年份容器，不修改 110 年題目資料。
5. 學生從 `/previous-exams` 選年份與科目；作答錯誤會寫入既有錯題中心，題目頁提供列印、正式詳解與 Novi 提問。

## 產品行為

- 題庫預設為草稿且關閉，避免尚未審核的題目被學生看到。
- 後台必須先發布才能開放；可隨時關閉，關閉後保留歷史作答紀錄。
- 學生端不會在尚未開放時顯示題庫。
- 答案在送出前不會回傳；送出後才顯示標準答案與詳解。
- 錯題沿用既有 `wrong_questions`，不另建孤立錯題系統。
- AI 只收到正式題幹、選項與已入庫詳解；資料不足時必須明確說明，不應自行補答案。
