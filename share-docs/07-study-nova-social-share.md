# StudyNova AI｜讓學習更容易開始

## 給同學的一段話

如果你也常常不知道今天要讀什麼、筆記和錯題散落在不同地方，或是想問 AI 卻不知道怎麼開始，可以試試 **StudyNova AI**。

StudyNova 不是只會叫你完成更多任務的工具，而是一個把學習計畫、AI 問答、單字、錯題、作文、成績、檔案處理與同學互動放在一起的學習平台。你可以從首頁查看今日建議，也可以直接點右下角的 **Novi AI**，問它：「我今天只有 20 分鐘，建議做什麼？」

## 你可能會喜歡的功能

- **Novi AI 助理**：右下角直接開聊，可以切換解題、提示、學習教練、考試、筆記、錯題與複習模式。
- **今日學習建議**：不知道從哪裡開始時，先挑一個適合現在狀態的方向，不需要一次完成全部內容。
- **智慧檔案壓縮**：圖片與 PDF 可以批次壓縮，指定目標大小，預覽結果後打包成 ZIP。
- **資料匯出中心**：可選擇個人的單字、錯題、測驗、筆記、成績與專注紀錄，預覽真正的 PDF、CSV、JSON 或其他格式成品後再下載。
- **作文與成績分析**：取得英文作文修正建議，並查看自己的學習與成績變化。
- **好友挑戰與讀書房**：用 NOVA ID 加好友、發起挑戰，或和同學一起加入讀書房。

## 三分鐘開始

1. 使用 Chrome 或 Safari 開啟 StudyNova 網站。
2. 註冊或登入帳號。
3. 查看首頁的今日建議。
4. 點右下角 Novi，問它一個你現在真的想解決的學習問題。

> 你不需要先準備好完整計畫，也不需要一次做到完美。先問一個問題、複習一題錯題，或完成五分鐘的學習，就是很好的開始。

## 安全提醒

請使用自己的帳號，不要分享密碼、驗證碼、API Key、Token 或私人檔案。如果遇到錯誤，請保留畫面上的 `SN-` 錯誤代碼與 request ID，再回報問題。
